# Emil Design Engineering

Source: https://github.com/emilkowalski/skill/blob/main/skills/emil-design-eng/SKILL.md

Use this local pointer before polishing Herencia 90 UI. Main principles:

- Tiny details compound into a premium interface.
- Animation should have a reason, stay fast, and prefer transform or opacity.
- Buttons need tactile press feedback.
- Hover effects should be subtle and gated to pointer devices when possible.
- Avoid generic transitions like `transition: all`.
- Review UI with before, after, and why.
