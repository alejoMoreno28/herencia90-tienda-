# Impeccable

Source: https://github.com/pbakaus/impeccable

Use this local pointer for frontend audit, polish, hierarchy, spacing, copy, and anti-pattern checks. Main principles:

- Minimalism needs precision, not emptiness.
- Every word earns its place.
- Cards are not the default answer. Use them when they communicate hierarchy.
- Avoid nested cards, over-explaining sections, gradient text, generic glassmorphism, and repeated identical card grids.
- Pick a color strategy before adding new colors.
- Keep typography hierarchy clear through scale and weight, not extra labels.
