# Design Taste Frontend

Source: https://github.com/Leonxlnx/taste-skill

Use this local pointer when the page starts feeling generic or too text-heavy. Main principles:

- Work with the existing stack.
- No unnecessary new dependencies.
- Strong layout, spacing, typography, and restrained motion beat decorative clutter.
- Keep visual density moderate for shopping: enough information to decide, little enough to scan.
- Use skeletons, empty states, and errors that match the actual layout.
- Prefer focused, reviewable improvements over broad redesigns.
